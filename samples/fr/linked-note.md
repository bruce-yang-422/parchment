# Exemple de note liée

Cette seconde note illustre les liens entre notes. Elle est liée et intégrée depuis le [[parchment-guide|Guide d’utilisation de Parchment]] ; l’onglet « Liens retour » indique donc sa provenance.

## Section intégrable

Cette section est intégrée dans le guide. Une intégration reprend tout le contenu sous le titre choisi jusqu’au titre suivant de même niveau, listes et tableaux compris.

- Le contenu intégré possède son propre cadre
- Sélectionnez le nom de la note au-dessus du cadre pour ouvrir la note source

| Syntaxe | Résultat |
| --- | --- |
| `[[note]]` | Lien vers une autre note |
| `[[note#titre]]` | Lien vers une section d’une note |
| `![[note#titre]]` | Intègre cette section |

## Intégrer un seul bloc

Ajoutez un identifiant de bloc à la fin d’un paragraphe pour n’intégrer que celui-ci. L’identifiant est masqué pendant la lecture. ^summary

Ce paragraphe n’a pas d’identifiant et n’est pas intégré.
