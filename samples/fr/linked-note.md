# Exemple de note liée

Cette seconde note illustre les liens entre notes. Elle est liée et intégrée depuis le [[parchment-guide|Guide d’utilisation de Parchment]] ; l’onglet « Liens retour » indique donc sa provenance.

## Section intégrable

Cette section est intégrée dans le guide. L’intégration reprend tout le contenu sous le titre sélectionné jusqu’au prochain titre de même niveau.

- Le contenu intégré possède sa propre bordure
- Cliquez sur le nom de la note pour ouvrir la source

## Intégrer un seul bloc

Ajoutez un identifiant de bloc à la fin d’un paragraphe pour n’intégrer que ce bloc. L’identifiant est masqué pendant la lecture. ^summary

Ce paragraphe n’a pas d’identifiant et n’est pas intégré.
