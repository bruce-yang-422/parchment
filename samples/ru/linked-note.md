# Пример связанной заметки

Эта вторая заметка-пример показывает ссылки между заметками. На неё ссылается и её встраивает [[parchment-guide|Руководство Parchment]], поэтому вкладка «Обратные ссылки» показывает, откуда пришла ссылка.

## Встраиваемый раздел

Этот раздел встроен в руководство. Встраивание забирает всё, что находится под выбранным заголовком, до следующего заголовка того же уровня, включая списки и таблицы.

- Встроенное содержимое получает собственную рамку
- Нажмите имя заметки над рамкой, чтобы открыть исходную заметку

| Синтаксис | Результат |
| --- | --- |
| `[[заметка]]` | Ссылка на другую заметку |
| `[[заметка#заголовок]]` | Ссылка на раздел заметки |
| `![[заметка#заголовок]]` | Встраивает этот раздел |

## Встроить один блок

Добавьте идентификатор блока в конец абзаца, чтобы встроить только его. При чтении идентификатор скрыт. ^summary

У этого абзаца нет идентификатора, поэтому он не встраивается.
