# Beispiel für eine verknüpfte Notiz

Diese zweite Beispielnotiz zeigt Verknüpfungen zwischen Notizen. Sie wird im [[parchment-guide|Parchment-Benutzerhandbuch]] verknüpft und eingebettet, daher zeigt die Registerkarte „Rückverweise“ ihre Quelle an.

## Einbettbarer Abschnitt

Dieser Abschnitt wird in das Benutzerhandbuch eingebettet. Die Einbettung enthält den Inhalt unter der gewählten Überschrift bis zur nächsten Überschrift derselben Ebene.

- Eingebettete Inhalte haben einen eigenen Rahmen
- Über den Notiznamen wird die ursprüngliche Notiz geöffnet

## Nur einen Block einbetten

Mit einer Block-ID am Absatzende kann nur dieser Absatz eingebettet werden. Die ID ist beim Lesen ausgeblendet. ^summary

Dieser Absatz hat keine Block-ID und wird nicht eingebettet.
