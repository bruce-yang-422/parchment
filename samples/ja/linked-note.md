# ノートリンクのサンプル

2 つ目のサンプルノートです。[[parchment-guide|Parchment ユーザーガイド]]からリンク・埋め込みされているため、「バックリンク」タブでリンク元を確認できます。

## 埋め込み可能なセクション

このセクションはユーザーガイドに埋め込まれます。指定した見出しから次の同じレベルの見出しまでが表示されます。

- 埋め込みコンテンツには専用の枠線が付きます
- 上部のノート名をクリックすると元のノートを開けます

## 1 ブロックだけを埋め込む

段落の末尾にブロック ID を追加すると、その段落だけを埋め込めます。閲覧時には ID が非表示になります。 ^summary

この段落にはブロック ID がないため埋め込まれません。
