# ノートリンクのサンプル

2 つ目のサンプルノートで、ノート同士のリンクを紹介します。[[parchment-guide|Parchment ユーザーガイド]]からリンク・埋め込みされているので、右側の「バックリンク」タブでリンク元を確認できます。

## 埋め込み可能なセクション

このセクションはユーザーガイドに埋め込まれています。`![[ノート#見出し]]` で埋め込むと、その見出しから次の同じレベルの見出しまでの内容が、リストや表も含めてまとめて表示されます。

- 埋め込まれた内容には枠が付きます
- 枠の上にあるノート名をクリックすると、元のノートが開きます

| 書き方 | 効果 |
| --- | --- |
| `[[ノート]]` | 別のノートにリンク |
| `[[ノート#見出し]]` | ノートのセクションにリンク |
| `![[ノート#見出し]]` | そのセクションを埋め込む |

## 1 ブロックだけを埋め込む

段落の末尾にブロック ID を付けると、その段落だけを埋め込めます。ID は閲覧中は表示されません。 ^summary

この段落にはブロック ID がないため、埋め込まれません。
