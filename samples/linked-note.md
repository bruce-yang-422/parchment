# 筆記連結範例

這是第二份範例筆記，用來示範筆記之間的連結。它被 [[parchment-guide|Parchment 使用導覽]] 連結與內嵌，所以在右側的「雙向連結」頁籤中，可以看到是哪一份筆記連到了這裡。

## 可以被內嵌的段落

這一段被內嵌到使用導覽中。用 `![[筆記#標題]]` 內嵌時，會帶入這個標題底下的所有內容，直到下一個同級標題為止，清單與表格也會一起帶入。

- 內嵌內容會有自己的外框
- 點擊外框上方的名稱，就會開啟原本的筆記

| 寫法 | 效果 |
| --- | --- |
| `[[筆記]]` | 連到另一份筆記 |
| `[[筆記#標題]]` | 連到筆記中的某一節 |
| `![[筆記#標題]]` | 把那一節內嵌進來 |

## 只內嵌一個區塊

在段落結尾加上 `^區塊名稱`，就可以只內嵌這一段。閱讀時，這個標記會自動隱藏。 ^summary

這一段沒有標記，所以不會被內嵌。
