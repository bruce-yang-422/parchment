隱私權政策

生效日期：2026 年 11 月 24 日

Parchment 為使用不同語言的讀者提供本機閱讀服務。無論使用哪一種介面或政策語言，以下共通的隱私原則都適用。

本政策適用於 Parchment 網站（parchment.stack-base.com）、安裝後的 Parchment 應用程式（PWA），以及 Chrome／Edge 的 Parchment 瀏覽器外掛和 Flutter Android／iOS 手機 App。Parchment 是本機 Markdown 與純文字檔案的唯讀優先閱讀器，設計目標是讓你的文件不離開你的裝置。

摘要

  • 我們不收集任何個人資料、檔案內容或使用統計。
  • 沒有帳號、沒有分析工具、沒有廣告或追蹤程式碼。
  • 文件只在你的瀏覽器或手機 App 中處理，不會上傳；只有你明確確認儲存時，手機 App 才會寫回 TODO 勾選。

我們收集的資料

無。Parchment 不收集、傳送、出售或分享任何個人資料、瀏覽紀錄、檔案內容或使用統計，也不會連線到開發者經營的任何伺服器。 所有程式碼（包含 Markdown、圖表與數學公式引擎）都隨網站、外掛或手機 App 提供，執行時不會從 CDN 下載其他程式碼。

你開啟的檔案

當你在 Parchment 中開啟檔案或資料夾，或在瀏覽器外掛開啟「允許存取檔案網址」後於瀏覽器中開啟本機 .md 檔時， Parchment 只會為了顯示而讀取這些檔案。內容只在你的瀏覽器或手機 App 中處理，「存成 PNG」也只在本機轉換。

手機 App 以 Android Storage Access Framework 或系統選檔器取得你主動選擇的單一文件或資料夾，不會掃描未授權的位置。單檔模式只接受 .md 與 .txt。Android 可保留你授予的資料夾存取權，讓你從最近資料夾重新開啟；你可以在 App 中移除該紀錄並釋放授權。 從其他 App 使用「開啟方式」或分享傳入的文件，也只會在 Parchment 中本機讀取。

手機 App 預設不修改文件。TODO 工作清單的勾選是唯一例外：變更先留在記憶體中，只有你選擇「存回原本的檔案」時才寫入；App 只替換勾選標記，並在寫入前檢查檔案是否已被其他程式修改。你也可以選擇另存新檔，原檔不會改變。

網站與 PWA 的本機儲存

為了提供以下功能，Parchment 會使用瀏覽器提供的本機儲存空間。這些資料只存在你的瀏覽器中，不會傳送到任何地方：

  • localStorage：配色、明暗模式、字型、閱讀寬度、側欄寬度、檔案樹排序方式、各文件的閱讀位置、工作清單勾選狀態，以及安裝提示的提醒時間。
  • IndexedDB：最近開啟的檔案與資料夾的控制代碼、名稱與時間，方便你再次開啟。重新開啟時，瀏覽器會視需要再次請求授權。
  • Service Worker 快取（僅網站與 PWA）：網站本身的程式與樣式，讓你可以離線使用。快取中不包含你的文件。

你可以透過瀏覽器的「清除網站資料」功能刪除網站資料。

瀏覽器外掛的權限

  • chrome.storage（僅瀏覽器外掛）：「以 Parchment 開啟本機 Markdown 檔」的設定。
  • storage：保存「以 Parchment 開啟本機 Markdown 檔」的設定。
  • 存取 file:///*：讀取你在瀏覽器中開啟的本機 .md 檔，以及同一資料夾中被引用的圖片與文件，以便顯示。瀏覽器只有在你自行開啟「允許存取檔案網址」後才會授予此權限。

外掛不要求任何網站的存取權限，也不會讀取你瀏覽的網頁。移除外掛即可刪除外掛資料。

手機 App 的權限與本機處理

  • 手機 App 本機偏好設定：配色、字型、字級等閱讀設定，以及最近資料夾的名稱、Android 文件 URI、開啟時間與系統授權狀態。文件內容不會保存到偏好設定中。你可以移除最近資料夾；解除安裝會清除本機偏好設定。
  • 文件與資料夾存取：只存取你透過系統選檔器主動選擇或由其他 App 分享給 Parchment 的文件。App 不要求傳統的廣泛儲存空間權限。
  • 讀寫權限：讀取用於顯示；寫入只發生在你明確儲存 TODO 勾選或另存新檔時。
  • 離線圖表：Mermaid、Graphviz 與 DOMPurify 隨 App 封裝，在隱藏的本機 WebView 中執行，不依賴外部 CDN，也不會把圖表原始碼送到網路。
  • 網路：使用系統字型或 App 內建字型時，閱讀本機文件與產生圖表都在手機上完成，不需要連線。以下情況裝置會連線：你開啟隱私權政策或官方網站；你點選文件中的網址並在確認視窗選擇「開啟」（交給瀏覽器或郵件 App 處理）；文件引用遠端圖片；或你在閱讀設定中選用標示下載圖示的 Google Fonts 字型（第一次使用時從 Google 下載並存在手機上，之後可離線使用）。遠端圖片由 App 直接向文件指定的網址請求，設有逾時及 20 MiB 上限；請求會附上 App 名稱、版本、作業系統與官方網站網址（例如 Parchment/1.1.5 (android; +https://parchment.stack-base.com)），這是維基百科等圖庫要求的識別方式，不含任何個人資料。該網站仍可能看到 IP 位址等一般連線資訊，但 Parchment 不會把文件內容一併送出。下載的圖片只暫存在記憶體中，關閉 App 後即清除。下載字型只會送出字型檔的請求，不會傳送文件內容。

第三方服務

  • 網站由 GitHub Pages 託管。GitHub 可能依其隱私權聲明記錄存取紀錄（例如 IP 位址）。瀏覽器外掛的內容全部打包在外掛中，使用時不會連線到 GitHub。
  • 如果你開啟的文件引用遠端內容（例如網站上的圖片），瀏覽器會像載入一般網頁一樣向該網址取得資源，這些請求受該網站的政策規範。
  • 手機 App 選用 Google Fonts 字型時，字型檔由 Google 的伺服器（fonts.gstatic.com）提供；Google 可能依其字型隱私說明記錄請求資訊（例如 IP 位址）。使用系統字型或內建字型則不會連線。
  • 從 GitHub Releases 下載瀏覽器外掛或 Android APK 時，GitHub 可能依其隱私權聲明記錄下載請求（例如 IP 位址）。安裝後使用時不會連線到 GitHub。
  • 如果你透過 Google Play 或其他應用程式商店取得手機 App，商店可能依其自身政策處理下載、安裝、付款或診斷資料；Parchment 開發者不會在 App 中加入分析或追蹤 SDK。

Privacy Policy

Effective date: November 24, 2026

Parchment provides local reading for people who use different languages. The same privacy principles apply regardless of your interface or policy language.

This policy applies to the Parchment website (parchment.stack-base.com), the installed Parchment app (PWA), and the Parchment browser extension for Chrome and Edge, and the Flutter app for Android and iOS. Parchment is a read-only-first reader for local Markdown and plain-text files, designed so that your documents never leave your device.

Summary

  • We do not collect any personal data, file contents or usage statistics.
  • No accounts, no analytics, no advertising or tracking code.
  • Documents are processed only in your browser or mobile app and are never uploaded. The mobile app writes TODO checkbox changes only after you explicitly confirm a save.

Data we collect

None. Parchment does not collect, transmit, sell or share any personal data, browsing history, file contents or usage statistics, and it does not connect to any server operated by the developer. All code, including the Markdown, diagram and math engines, ships with the website or the extension or mobile app; no other code is downloaded from a CDN at run time.

Files you open

When you open a file or folder in Parchment, or open a local .md file in the browser after turning on "Allow access to file URLs" for the extension, Parchment reads those files only to display them. Content is processed only in your browser or mobile app. "Save as PNG" also converts images locally.

The mobile app uses Android's Storage Access Framework or the platform file picker to access only the file or folder you select. It does not scan unauthorized locations. Single-file mode accepts only .md and .txt. Android can retain a folder grant so it can appear in Recent Folders; removing it in the app releases that grant. Files received through another app's Open With or Share action are also read locally.

The mobile app does not modify documents by default. TODO checkbox changes remain in memory until you choose to save. Saving in place changes only checkbox markers and first checks whether another app has modified the file. Save As creates a new file and leaves the original unchanged.

Website and PWA local storage

To provide the features below, Parchment uses your browser's local storage. This data stays in your browser and is never sent anywhere:

  • localStorage: color palette, light/dark mode, fonts, reading width, sidebar widths, file tree sort order, reading position for each document, task-list checkbox states, and the install reminder time.
  • IndexedDB: handles, names and times of recently opened files and folders, so you can reopen them. The browser asks for permission again when needed.
  • Service worker cache (website and PWA only): the site's own code and styles, so it works offline. Your documents are not cached.

You can delete website data with your browser's "clear site data" feature.

Browser extension permissions

  • chrome.storage (browser extension only): the "open local Markdown files with Parchment" setting.
  • storage: saves the "open local Markdown files with Parchment" setting.
  • Access to file:///*: reads the local .md file you open in the browser, and the images and documents it references in the same folder, so they can be displayed. The browser grants this only after you turn on "Allow access to file URLs" yourself.

The extension requests no access to websites and does not read the web pages you visit. Removing the extension deletes its stored data.

Mobile app permissions and local processing

  • Mobile app local preferences: reading settings such as theme, font and text size, plus recent-folder names, Android document URIs, open times and grant state. Document contents are not stored in preferences. You can remove recent folders, and uninstalling deletes local preferences.
  • Files and folders: accesses only documents you select through the system picker or share with Parchment from another app. It does not request legacy broad storage permission.
  • Read and write access: reads files for display; writes only when you explicitly save TODO checkbox changes or use Save As.
  • Offline diagrams: Mermaid, Graphviz and DOMPurify ship with the app and run in a hidden local WebView. No CDN is required, and diagram source is not sent over the network.
  • Network: with the system font or a font bundled with the app, reading local documents and rendering diagrams happen on the phone without a connection. The device connects only when you open the privacy policy or the official website; when you tap a link in a document and choose Open in the confirmation dialog (it is handed to your browser or e-mail app); when a document references a remote image; or when you choose a Google Fonts typeface marked with a download icon in the reading settings (downloaded from Google the first time and stored on the phone for offline use). The app requests a remote image directly from the URL written in the document, with timeouts and a 20 MiB limit. The request identifies the app name, version, operating system and official website (for example Parchment/1.1.5 (android; +https://parchment.stack-base.com)), as image libraries such as Wikipedia require; it contains no personal data. Downloaded images are kept only in memory and are cleared when the app closes. That host may receive ordinary connection data such as your IP address, but Parchment does not send the document content with the request. A font download requests only the font file; document content is never sent.

Third-party services

  • The website is hosted on GitHub Pages. GitHub may log access information, such as IP addresses, under its privacy statement. The browser extension bundles all of its content and does not connect to GitHub.
  • If a document you open references remote content, such as an image hosted on a website, your browser requests it from that address as it would for any web page. Those requests are governed by that site's policies.
  • When the mobile app uses a Google Fonts typeface, the font file is served by Google (fonts.gstatic.com), which may log request information such as IP addresses under its fonts privacy FAQ. The system font and the bundled fonts need no connection.
  • When you download the browser extension or the Android APK from GitHub Releases, GitHub may log the download request, such as your IP address, under its privacy statement. The installed extension and app do not connect to GitHub.
  • If you obtain the mobile app through Google Play or another app store, the store may process download, installation, payment or diagnostic data under its own policy. The Parchment app contains no analytics or tracking SDK.

隐私政策

生效日期：2026 年 11 月 24 日

Parchment 为使用不同语言的读者提供本地阅读服务。无论选择哪种界面或政策语言，均适用相同的隐私原则。

Parchment 适用于网站、PWA、Chrome／Edge 扩展和 Android／iOS App。我们不收集、传送、出售或分享个人数据、浏览历史、文件内容或使用统计。没有账户、广告、分析或追踪代码。文件和 PNG 转换都在设备上处理。

网站与 PWA

主题、阅读位置、侧栏、排序、任务状态等设置保存在 localStorage；最近文件或文件夹的名称、时间与访问句柄保存在 IndexedDB。离线缓存只保存网站资源，不缓存你的文档。可在浏览器清除网站数据。

浏览器还会记录字体、阅读宽度、侧栏宽度、文件树排序、待办勾选和安装提醒。重新打开最近项目时，浏览器可能再次请求授权。

浏览器扩展

chrome.storage 只保存是否由 Parchment 打开本地 Markdown 的设置。只有你授予 file:// 权限后，扩展才读取你打开的 .md 文件和同一文件夹内引用的资源。扩展不读取浏览的网页。卸载即可删除扩展数据。

手机 App

仅通过系统文件选择器或其他 App 分享读取你授权的 .md、.txt 文件或文件夹。Android 可保留最近文件夹授权，移除记录即可撤销。仅在明确保存待办勾选或另存时写入；覆盖前会检查原文件是否改变。阅读设置与最近文件夹信息保存在设备上，卸载时清除。图表和公式引擎随 App 打包并在设备上运行。

App 不要求广泛的存储权限。保存到原文件时仅替换待办勾选标记；另存会创建新文件。偏好设置可能包含最近文件夹名称、Android 文档 URI、打开时间和授权状态，不包含文件内容。

第三方服务

GitHub Pages 托管网站，GitHub Releases 提供下载；GitHub 可能记录 IP 等连接信息。远程图片由设备直接请求，手机 App 限制为 20 MiB，发送 App 名称、版本、系统与官网作为识别信息，图片仅暂存在内存。选择下载型 Google Fonts 时会向 Google 请求字型文件。外部链接在确认后交给浏览器或邮件 App；应用商店按自身政策处理下载、安装、付款或诊断信息。

  • 图片服务器和 Google 可能记录 IP 等常规连接信息。字体下载请求仅用于获取字体文件；图片和字体请求均不发送文档内容。
  • 应用商店可能按自身政策处理下载、安装、付款或诊断数据。Parchment 不包含分析或追踪 SDK。

プライバシーポリシー

発効日：2026年11月24日

Parchment はさまざまな言語の読者に端末内での閲覧機能を提供します。表示言語やポリシーの言語にかかわらず、同じプライバシー原則が適用されます。

Parchment のウェブサイト、PWA、Chrome／Edge 拡張機能、Android／iOS アプリに適用されます。個人情報、閲覧履歴、ファイル内容、利用統計を収集・送信・販売・共有しません。アカウント、広告、解析、追跡はなく、文書の表示と PNG 変換は端末内で行います。

ウェブサイトと PWA

表示設定や読書位置などは localStorage、最近開いたファイルの名前、時刻、アクセス情報は IndexedDB に保存されます。オフラインキャッシュにはサイトの素材のみが入り、文書は含まれません。ブラウザーからサイトデータを削除できます。

フォント、本文とサイドバーの幅、ファイルの並び順、タスクのチェック状態、インストール通知も端末内に保存します。最近の項目を開くとき、ブラウザーが再度許可を求める場合があります。

ブラウザー拡張機能

chrome.storage はローカル Markdown を開く設定を保持します。file:// の許可を有効にした場合のみ、開いた .md と同じフォルダーの参照資料を読みます。閲覧中のウェブページにはアクセスしません。拡張機能を削除すると保存データも消去されます。

モバイルアプリ

システムの選択画面や共有操作で指定した .md、.txt、フォルダーのみ読み取ります。Android の最近のフォルダーから削除すると許可を解除できます。チェック状態の保存や別名保存を明示的に行った場合のみ書き込みます。上書き前に外部変更を確認します。表示設定と最近のフォルダー情報は端末内に残り、アンインストールで消去されます。図と数式はオフラインで処理されます。

広範なストレージ権限は要求しません。上書き時はタスクのチェック記号のみ変更し、別名保存では新規ファイルを作成します。設定には最近のフォルダー名、Android の文書 URI、閲覧時刻と許可状態が含まれますが、文書の内容は保存しません。

第三者サービス

GitHub Pages や Releases はアクセス元 IP などを記録することがあります。外部画像は指定先に直接要求し、アプリでは上限 20 MiB、メモリ内のみで保持します。画像要求にはアプリ名、バージョン、OS、公式サイトが含まれます。ダウンロードを選んだ Google Fonts は Google から取得します。外部リンクは確認後にブラウザーやメールアプリへ渡し、アプリストアの処理には各ストアの方針が適用されます。

  • 画像の配信元や Google は IP アドレスなどの接続情報を記録する場合があります。フォント要求はファイルの取得のみを目的とし、画像やフォントの要求で文書を送信しません。
  • アプリストアはダウンロード、インストール、支払い、診断情報を独自の方針で扱う場合があります。Parchment には解析・追跡 SDK はありません。

개인정보 처리방침

시행일: 2026년 11월 24일

Parchment는 다양한 언어를 사용하는 독자에게 기기 내 읽기 기능을 제공합니다. 인터페이스나 정책 언어에 관계없이 동일한 개인정보 보호 원칙이 적용됩니다.

Parchment 웹사이트, PWA, Chrome／Edge 확장 프로그램 및 Android／iOS 앱에 적용됩니다. 개인정보, 방문 기록, 파일 내용, 사용 통계를 수집·전송·판매·공유하지 않습니다. 계정, 광고, 분석 및 추적 기능이 없으며 문서 표시와 PNG 변환은 기기에서 처리됩니다.

웹사이트 및 PWA

보기 설정과 읽기 위치 등은 localStorage에, 최근 파일·폴더의 이름, 시간 및 접근 핸들은 IndexedDB에 보관됩니다. 오프라인 캐시에는 사이트 리소스만 저장됩니다. 브라우저에서 사이트 데이터를 삭제할 수 있습니다.

글꼴, 본문과 사이드바 너비, 파일 정렬, 할 일 체크 상태와 설치 알림도 로컬에 저장됩니다. 최근 파일이나 폴더를 다시 열 때 브라우저가 권한을 재요청할 수 있습니다.

브라우저 확장 프로그램

chrome.storage는 로컬 Markdown 열기 설정을 저장합니다. file:// 접근을 허용한 경우에만 직접 연 .md 파일과 같은 폴더에서 참조하는 자료를 읽습니다. 방문한 웹페이지는 읽지 않으며 확장 프로그램을 삭제하면 저장 데이터도 삭제됩니다.

모바일 앱

시스템 선택기나 공유 기능으로 선택한 .md, .txt 및 폴더만 읽습니다. Android에서 최근 폴더를 삭제하면 접근 권한이 해제됩니다. 할 일 변경을 저장하거나 다른 이름으로 저장할 때만 파일에 쓰며, 덮어쓰기 전에 외부 변경을 확인합니다. 읽기 설정과 최근 폴더 정보는 기기에 저장되며 앱 삭제 시 제거됩니다. 도표와 수식은 오프라인에서 처리합니다.

앱은 광범위한 저장소 권한을 요청하지 않습니다. 원본 저장 시 할 일 체크 표시만 바꾸며, 다른 이름으로 저장하면 새 파일을 만듭니다. 설정에는 최근 폴더 이름, Android 문서 URI, 열었던 시간과 권한 상태가 포함되며 문서 내용은 저장되지 않습니다.

외부 서비스

GitHub Pages 및 Releases는 IP 등 접속 정보를 기록할 수 있습니다. 원격 이미지는 기기가 원본 주소에 직접 요청하며 모바일 앱은 20 MiB로 제한하고 메모리에만 보관합니다. 요청에는 앱 이름, 버전, OS 및 공식 사이트 주소가 포함됩니다. 다운로드형 Google Fonts를 선택하면 Google에 글꼴을 요청합니다. 확인한 외부 링크는 브라우저나 이메일 앱에서 열고, 앱 스토어에는 각 스토어의 정책이 적용됩니다.

  • 이미지 제공 사이트와 Google은 IP 등 연결 정보를 기록할 수 있습니다. 글꼴 요청은 파일을 가져오는 데만 사용되며, 이미지나 글꼴 요청에 문서 내용은 전송되지 않습니다.
  • 스토어는 다운로드, 설치, 결제 또는 진단 데이터를 자체 정책에 따라 처리할 수 있습니다. Parchment에는 분석 또는 추적 SDK가 없습니다.

Politique de confidentialité

Parchment permet de lire des documents localement dans différentes langues. Les mêmes principes de confidentialité s’appliquent à toutes les langues de l’interface et de cette politique.

Cette politique couvre le site et la PWA Parchment, l’extension Chrome／Edge et l’application Android／iOS. Parchment ne collecte, ne transmet, ne vend et ne partage ni données personnelles, ni historique, ni contenu de fichiers, ni statistiques. Sans compte, publicité, mesure d’audience ou suivi. Les documents et les conversions PNG sont traités sur l’appareil.

Site et PWA

Les réglages et positions de lecture sont conservés dans localStorage. IndexedDB conserve les noms, dates et accès aux fichiers ou dossiers récents. Le cache hors ligne contient uniquement les ressources du site. Vous pouvez effacer ces données dans le navigateur.

Le navigateur conserve aussi la police, les largeurs de lecture et des panneaux, le tri des fichiers, les cases cochées et le rappel d’installation. Il peut redemander l’autorisation lors de la réouverture d’un élément récent.

Extension de navigateur

chrome.storage conserve le réglage d’ouverture des fichiers Markdown locaux. Une fois l’accès file:// autorisé, l’extension lit les fichiers .md ouverts et les ressources référencées du même dossier. Elle ne lit pas les sites consultés. La désinstallation efface ses données.

Application mobile

Seuls les fichiers .md ou .txt et dossiers choisis via le sélecteur ou partagés avec l’application sont lus. Retirer un dossier récent révoque son autorisation Android. Seul l’enregistrement explicite des cases ou l’enregistrement sous un autre nom écrit sur le disque. Avant l’écrasement, l’application vérifie les modifications externes. Les préférences et dossiers récents sont stockés localement et supprimés à la désinstallation. Diagrammes et formules fonctionnent hors ligne.

L’application ne demande pas d’autorisation d’accès général au stockage. L’enregistrement sur place modifie uniquement les marques des cases, tandis que l’enregistrement sous un autre nom crée un fichier. Les préférences locales peuvent contenir les noms des dossiers, les URI Android, les dates d’ouverture et l’état des autorisations, sans le contenu des documents.

Services tiers

GitHub Pages et Releases peuvent journaliser les accès, dont les adresses IP. Les images distantes sont demandées directement à leur hôte. L’application les garde en mémoire, avec une limite de 20 Mio, et identifie son nom, sa version, le système et son site officiel. Les polices téléchargeables sélectionnées sont demandées à Google Fonts. Les liens confirmés s’ouvrent dans le navigateur ou la messagerie. Les boutiques appliquent leurs propres conditions de confidentialité.

  • Les hébergeurs d’images et Google peuvent enregistrer des données de connexion comme l’adresse IP. La demande de police sert uniquement à obtenir son fichier. Ni les demandes d’images ni celles de polices ne transmettent le document.
  • Les boutiques peuvent traiter les données de téléchargement, d’installation, de paiement ou de diagnostic selon leurs politiques. Parchment ne contient aucun SDK d’analyse ou de suivi.

Sitio web y PWA

La configuración y la posición de lectura se guardan en localStorage. IndexedDB conserva nombres, fechas y permisos de acceso de archivos o carpetas recientes. La caché sin conexión almacena únicamente recursos del sitio. Puedes borrar estos datos desde el navegador.

También se guardan la fuente, el ancho de lectura y de los paneles, el orden de archivos, las casillas de tareas y el recordatorio de instalación. El navegador puede volver a pedir permiso al reabrir un elemento reciente.

Extensión del navegador

chrome.storage guarda la opción de abrir Markdown local. Si autorizas el acceso file://, la extensión lee los archivos .md que abras y los recursos referenciados de la misma carpeta. No lee las páginas que visitas. Desinstalarla elimina los datos de la extensión.

Aplicación móvil

Solo lee los archivos .md y .txt y las carpetas que selecciones o compartas. Al quitar una carpeta reciente se revoca su permiso en Android. Solo escribe al guardar explícitamente las casillas de tareas o crear una copia, y comprueba cambios externos antes de sobrescribir. Las preferencias y las carpetas recientes se guardan localmente y se eliminan al desinstalar. Los diagramas y fórmulas funcionan sin conexión.

Политика конфиденциальности

Вступает в силу 24 ноября 2026 года

Parchment позволяет читать документы локально на разных языках. Независимо от языка интерфейса или политики действуют одинаковые принципы конфиденциальности.

Политика распространяется на сайт и PWA, расширение Chrome／Edge и приложение для Android／iOS. Parchment не собирает, не передаёт, не продаёт и не раскрывает персональные данные, историю просмотра, содержимое файлов и статистику использования. Аккаунты, реклама, аналитика и отслеживание отсутствуют. Документы и PNG обрабатываются на устройстве.

Сайт и PWA

Настройки и позиции чтения хранятся в localStorage. В IndexedDB сохраняются имена, время и ссылки доступа к недавним файлам и папкам. Офлайн-кеш содержит только ресурсы сайта. Данные сайта можно удалить в браузере.

Локально сохраняются также шрифты, ширина области чтения и боковых панелей, сортировка файлов, отметки задач и напоминания об установке. При повторном открытии браузер может снова запросить разрешение.

Расширение браузера

В chrome.storage хранится настройка открытия локальных Markdown-файлов. После разрешения file:// расширение читает открытые вами файлы .md и ресурсы из той же папки. Посещаемые страницы оно не читает. При удалении расширения удаляются его данные.

Мобильное приложение

Читает только выбранные или переданные файлы .md, .txt и папки. Удаление недавней папки отзывает разрешение Android. Запись выполняется при явном сохранении отметок задач или сохранении копии. Перед перезаписью проверяются внешние изменения. Настройки и сведения о недавних папках хранятся на устройстве и удаляются при деинсталляции. Формулы и диаграммы обрабатываются офлайн.

Приложение не запрашивает общий доступ к хранилищу. При сохранении в исходный файл меняются только отметки задач. Сохранение копии создаёт новый файл. Настройки могут содержать имена папок, URI документов Android, время открытия и состояние разрешений, но не содержимое документов.

Сторонние службы

GitHub Pages и Releases могут регистрировать IP и другие сведения о подключении. Изображения запрашиваются у их владельцев и хранятся в памяти приложения с лимитом 20 МиБ. Запрос содержит название и версию приложения, ОС и адрес сайта. Выбранные шрифты загружаются из Google Fonts. Внешние ссылки после подтверждения передаются браузеру или почтовому приложению. Магазины приложений применяют собственные правила.

  • Серверы изображений и Google могут регистрировать IP-адрес и другие данные подключения. Запрос шрифта предназначен только для получения файла шрифта. Запросы изображений и шрифтов не передают содержимое документов.
  • Магазины могут обрабатывать данные загрузки, установки, оплаты или диагностики по собственным правилам. В Parchment нет SDK аналитики или отслеживания.
