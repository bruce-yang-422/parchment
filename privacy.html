隱私權政策

生效日期：2026 年 11 月 19 日

本政策適用於 Parchment 網站（bruce-yang-422.github.io/parchment）、安裝後的 Parchment 應用程式（PWA），以及 Chrome 與 Edge 的 Parchment 瀏覽器外掛。Parchment 是本機 Markdown 與純文字檔案的唯讀閱讀器，設計目標是讓你的文件不離開你的裝置。

摘要

  • 我們不收集任何個人資料、檔案內容或使用統計。
  • 沒有帳號、沒有分析工具、沒有廣告或追蹤程式碼。
  • 文件只在你的瀏覽器中以唯讀方式讀取與顯示，不會被修改或上傳。

我們收集的資料

無。Parchment 不收集、傳送、出售或分享任何個人資料、瀏覽紀錄、檔案內容或使用統計，也不會連線到開發者經營的任何伺服器。 所有程式碼（包含 Markdown、圖表與數學公式引擎）都隨網站或外掛提供，執行時不會下載其他程式碼。

你開啟的檔案

當你在 Parchment 中開啟檔案或資料夾，或在瀏覽器外掛開啟「允許存取檔案網址」後於瀏覽器中開啟本機 .md 檔時， Parchment 只會為了顯示而讀取這些檔案。檔案以唯讀方式開啟，內容只在你的瀏覽器中處理。「存成 PNG」也是在本機轉換後直接下載。

儲存在你裝置上的資料

為了提供以下功能，Parchment 會使用瀏覽器提供的本機儲存空間。這些資料只存在你的瀏覽器中，不會傳送到任何地方：

  • localStorage：配色、明暗模式、字型、閱讀寬度、側欄寬度、檔案樹排序方式、各文件的閱讀位置、工作清單勾選狀態，以及安裝提示的提醒時間。
  • IndexedDB：最近開啟的檔案與資料夾的控制代碼、名稱與時間，方便你再次開啟。重新開啟時，瀏覽器會視需要再次請求授權。
  • Service Worker 快取（僅網站與 PWA）：網站本身的程式與樣式，讓你可以離線使用。快取中不包含你的文件。
  • chrome.storage（僅瀏覽器外掛）：「以 Parchment 開啟本機 Markdown 檔」的設定。

你可以隨時透過瀏覽器的「清除網站資料」功能刪除網站資料，或移除瀏覽器外掛以刪除外掛的資料。

瀏覽器外掛的權限

  • storage：保存「以 Parchment 開啟本機 Markdown 檔」的設定。
  • 存取 file:///*：讀取你在瀏覽器中開啟的本機 .md 檔，以及同一資料夾中被引用的圖片與文件，以便顯示。瀏覽器只有在你自行開啟「允許存取檔案網址」後才會授予此權限。

外掛不要求任何網站的存取權限，也不會讀取你瀏覽的網頁。

第三方服務

  • 網站由 GitHub Pages 託管。GitHub 可能依其隱私權聲明記錄存取紀錄（例如 IP 位址）。瀏覽器外掛的內容全部打包在外掛中，使用時不會連線到 GitHub。
  • 如果你開啟的文件引用遠端內容（例如網站上的圖片），瀏覽器會像載入一般網頁一樣向該網址取得資源，這些請求受該網站的政策規範。

政策變更

本政策若有變更，會更新於本頁並修改上方的生效日期。

Privacy Policy

Effective date: November 19, 2026

This policy applies to the Parchment website (bruce-yang-422.github.io/parchment), the installed Parchment app (PWA), and the Parchment browser extension for Chrome and Edge. Parchment is a read-only reader for local Markdown and plain-text files, designed so that your documents never leave your device.

Summary

  • We do not collect any personal data, file contents or usage statistics.
  • No accounts, no analytics, no advertising or tracking code.
  • Documents are read and displayed read-only in your browser. They are never modified or uploaded.

Data we collect

None. Parchment does not collect, transmit, sell or share any personal data, browsing history, file contents or usage statistics, and it does not connect to any server operated by the developer. All code, including the Markdown, diagram and math engines, ships with the website or the extension; no other code is downloaded at run time.

Files you open

When you open a file or folder in Parchment, or open a local .md file in the browser after turning on "Allow access to file URLs" for the extension, Parchment reads those files only to display them. Files are opened read-only and processed only in your browser. "Save as PNG" also converts and downloads images locally.

Data stored on your device

To provide the features below, Parchment uses your browser's local storage. This data stays in your browser and is never sent anywhere:

  • localStorage: color palette, light/dark mode, fonts, reading width, sidebar widths, file tree sort order, reading position for each document, task-list checkbox states, and the install reminder time.
  • IndexedDB: handles, names and times of recently opened files and folders, so you can reopen them. The browser asks for permission again when needed.
  • Service worker cache (website and PWA only): the site's own code and styles, so it works offline. Your documents are not cached.
  • chrome.storage (browser extension only): the "open local Markdown files with Parchment" setting.

You can delete website data at any time with your browser's "clear site data" feature, or remove the extension to delete its data.

Browser extension permissions

  • storage: saves the "open local Markdown files with Parchment" setting.
  • Access to file:///*: reads the local .md file you open in the browser, and the images and documents it references in the same folder, so they can be displayed. The browser grants this only after you turn on "Allow access to file URLs" yourself.

The extension requests no access to websites and does not read the web pages you visit.

Third-party services

  • The website is hosted on GitHub Pages. GitHub may log access information, such as IP addresses, under its privacy statement. The browser extension bundles all of its content and does not connect to GitHub.
  • If a document you open references remote content, such as an image hosted on a website, your browser requests it from that address as it would for any web page. Those requests are governed by that site's policies.

Changes to this policy

Any changes will be posted on this page with an updated effective date.

Contact
