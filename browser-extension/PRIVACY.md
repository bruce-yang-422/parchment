# Parchment browser extension — Privacy policy / 隱私權政策

Last updated / 最後更新：2026-11-19

## English

Parchment is a read-only reader for local Markdown and plain-text files. It is designed so that your documents never leave your device.

**Data we collect.** None. The extension does not collect, transmit, sell or share any personal data, browsing history, file contents or usage statistics. It contains no analytics, advertising or tracking code, and it does not contact any server operated by the developer.

**Files you open.** When you open a file or folder in Parchment, or open a local `.md` file in the browser while "Allow access to file URLs" is enabled, the extension reads that file only to display it in your browser. Files are opened read-only and are never modified or uploaded.

**Data stored on your device.** The following stays in your browser's storage for this extension and is never sent anywhere:

- Your settings, such as color palette, light/dark mode, fonts and reading width.
- Reading positions and task-list checkbox states.
- Handles to recently opened files and folders, so you can reopen them. The browser asks for permission again when needed.

You can remove all of this at any time by uninstalling the extension.

**Permissions.**

- `storage`: saves the "open local Markdown files with Parchment" setting.
- Access to `file:///*`: reads the local `.md` file you open in the browser so it can be displayed. The browser only grants this after you turn on "Allow access to file URLs" yourself.

**External resources.** If a document you open references remote content, such as an image hosted on a website, your browser loads it from that address, as it would for any web page.

**Contact.** Questions can be filed as an issue at <https://github.com/bruce-yang-422/parchment/issues>.

## 繁體中文

Parchment 是本機 Markdown 與純文字檔案的唯讀閱讀器，設計目標是讓你的文件不離開你的裝置。

**我們收集的資料**：無。本外掛不收集、傳送、出售或分享任何個人資料、瀏覽紀錄、檔案內容或使用統計；不含任何分析、廣告或追蹤程式碼，也不會連線到開發者經營的任何伺服器。

**你開啟的檔案**：當你在 Parchment 中開啟檔案或資料夾，或在開啟「允許存取檔案網址」後於瀏覽器中開啟本機 `.md` 檔時，本外掛只會為了在瀏覽器中顯示而讀取該檔案。檔案以唯讀方式開啟，不會被修改或上傳。

**儲存在你裝置上的資料**：以下資料保存在瀏覽器為本外掛提供的儲存空間，不會傳送到任何地方：

- 你的設定，例如配色、明暗模式、字型與閱讀寬度。
- 閱讀位置與工作清單的勾選狀態。
- 最近開啟的檔案與資料夾控制代碼，方便重新開啟；必要時瀏覽器會再次請求授權。

移除本外掛即可隨時清除上述所有資料。

**權限**：

- `storage`：保存「以 Parchment 開啟本機 Markdown 檔」的設定。
- 存取 `file:///*`：讀取你在瀏覽器中開啟的本機 `.md` 檔以便顯示。瀏覽器只有在你自行開啟「允許存取檔案網址」後才會授予此權限。

**外部資源**：如果你開啟的文件引用遠端內容（例如網站上的圖片），瀏覽器會像載入一般網頁一樣，向該網址取得資源。

**聯絡方式**：如有疑問，請至 <https://github.com/bruce-yang-422/parchment/issues> 提出 Issue。
